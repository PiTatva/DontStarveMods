# Don't Starve Mods
List of mods to make your gameplay better. Most of the mods here work for Vanilla and Dlc(RoG,Shipwreck) . I've made lot of balance adjustments & merged many mods here so some mods can change gameplay drastically . It's upto you to disable those in mods menu if u want. 

## Installation : 

Make a 'mods' named folder where launcher.exe is present . Put all these files there . Done !!! If game crashes , try enabling each mod one by one. 
All the description of Mods can be found in the mods menu inside the game.
